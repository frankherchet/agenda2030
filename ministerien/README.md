# Ministerien

Dieser Bereich ordnet Maßnahmen nach fachlicher Federführung. Ein Vorschlag
kann mehrere Ressorts betreffen; in diesem Fall sollte er im federführenden
Ministerium liegen und die Mitwirkung weiterer Ministerien nennen.
