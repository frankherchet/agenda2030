# Rentenversicherung

Arbeitsordner fuer Daten, Auswertungen und Modelle zur gesetzlichen
Rentenversicherung.

## Struktur

- `daten/`: maschinenlesbare Zwischen- und Ergebnisdaten.
- `auswertungen/`: Markdown-Auswertungen, die in Reformreports zitiert werden.

## Aktuelle Modelle

- Abschmelzmodell fuer den Bestandsschutz-Zuschuss:
  `auswertungen/2026-06-04-bundeszuschuss-abschmelzung.md`
